10:T4a1,<p>The pull a remembered category exerts on a specific memory — the detail drifts toward the prototype the way a river bends toward the sea, and finer categories make a shorter bend.</p>
<p>A child asked to remember &quot;the red apple&quot; will later recall a redder apple than it was, because &quot;apple&quot; pulls the memory toward the typical apple; asked to remember &quot;the Fuji apple&quot; the drift is smaller, because the finer category has a tighter center. The category-adjustment model (Huttenlocher) is one law across location, length, and duration: the category pulls only when it is <em>used</em>, so labels help a near-boundary value (pulling it home) and harm a sub-categorical one (pulling it away from its true detail).</p>
