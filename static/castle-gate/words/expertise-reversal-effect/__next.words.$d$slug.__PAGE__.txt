2:Tca8,<p>When you get good at something, the help that got you there starts getting in your way — the scaffold that held you up becomes the thing you must step around.</p>
<p>The expertise reversal effect (Kalyuga, Ayres, Chandler &amp; Sweller, 2003) holds that instructional techniques helping novices build <a href="/castle-gate/words/schema">schemas</a> become redundant for experts who already have them — and the redundancy is not neutral: processing the now-unnecessary guidance costs working memory, so the same explanation that lifted the beginner degrades the expert. Worked examples, the most validated tool in instructional design, reverse their sign: novices learn faster from worked examples than from problem-solving, but experts learn faster from problem-solving than from studying worked examples they no longer need.</p>
<p>The effect is not a smooth gradient but a piecewise flip: as the learner's own schema grows, each piece of external guidance crosses a threshold where it stops helping and starts hindering, one step at a time. The fading experiments found the best results when each scaffold step was removed only once the learner produced it unprompted — the flip is per-step, not all at once. This is the law the castle's <a href="/castle-gate/rooms/when-the-trade-flips">when-the-trade-flips</a> room translates into three felt signs: you arrive before the guide, help feels like drag, and the cover test confirms it.</p>
<p>The effect appears across the castle in rooms that never named it directly: - In the tacit wing, it predicts that forcing an expert to verbalise automatic steps adds load without revealing the tacit — the <a href="/castle-gate/words/procedural-knowledge">procedural-knowledge</a> that runs silently is degraded, not illuminated, by the guidance the expert no longer needs (<a href="/castle-gate/rooms/reactivity-surfaces-tacit">reactivity-surfaces-tacit</a>, <a href="/castle-gate/rooms/think-aloud-annotated-checklist">think-aloud-annotated-checklist</a>). - In the teachability wing, it names the transition point where instructional guidance stops helping and a learning threshold might sit — the feature that predicts the threshold is <a href="/castle-gate/words/element-interactivity">element-interactivity</a>, the same concept that decides where &quot;why difficulty helps&quot; stops being true (<a href="/castle-gate/rooms/threshold-pilot">threshold-pilot</a>, <a href="/castle-gate/rooms/rationale-before-difficulty">rationale-before-difficulty</a>). - In the tacit-cost wing, it predicts the gap between silent and concurrent expert judgment narrows rather than widens — the expert's explicit layer becomes richer and more articulable, not poorer, because the schema is declarative and well-organised (<a href="/castle-gate/rooms/tacit-cost-as-expertise">tacit-cost-as-expertise</a>, <a href="/castle-gate/rooms/gap-predicts-teaching">gap-predicts-teaching</a>).</p>
<p>The effect's deepest implication is that expertise is not simply &quot;more of the same&quot; — it is a structural change where the relationship between the learner and the guidance inverts.
