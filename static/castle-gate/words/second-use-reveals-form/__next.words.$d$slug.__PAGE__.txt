<p>The principle: a single instance is epistemically indistinguishable from an accident. The second use — a <em>different</em> work reaching for the <em>same</em> shape, not the same work repeating it — is the evidence of choice. Repetition proves nothing; recurrence in a new context proves the shape was chosen for its own sake, not for the first work's needs. The first use is practice; the second is recognition; the name is articulation. You can name after one use, but it is a bet — the second use must confirm it, or the name is dead weight. The <a href="/castle-gate/words/wing-epigraph">wing-epigraph</a> form was named after one use (2026-06-22) and the bet held when the overview confirmed it (2026-06-25); the naming was a wager, and the second use made it load-bearing.</p>
<p>This is the temporal version of <a href="/castle-gate/rooms/link-or-noise">link-or-noise</a>, the founding law. link-or-noise says a link carries meaning when it is <em>chosen</em>, not found — chosen for a reason you could state. This principle says a shape becomes a craft when it is <em>chosen over time</em>, not chosen once. The first appearance could be an accident; the recurrence is the evidence it was not. link-or-noise asks whether a single link was chosen; this principle asks whether a shape was chosen <em>as a shape</em> — and the test is the same: can you state the reason it recurs? If the second work reached for the shape because it was the right shape, the form is real. If it reached for it because the first work left it lying around, the recurrence is inheritance, not choice — and a name on that foundation is dead weight.</p>
