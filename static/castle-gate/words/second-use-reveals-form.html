second-use-reveals-form

craft-after-practice named the lag between practice and name. But the lag holds two events, and craft-after-practice named the later one: the naming. The earlier event is the recognition, and it arrives at the second use. The first use practices the shape; the second use reveals it; the name only carries the recognition forward in words. The pattern is not "name after practice" but "recognize at two, name when certain."

The castle has lived this in every craft it has named:

  • representative-shifts-with-boundaries: The short tour combined wings III and IV and chose the hinge room (2026-06-19). The overview separated them and chose each wing's founding room (2026-06-25). The short tour's choice alone could have been arbitrary — a single instance cannot prove the shape was chosen rather than merely arrived. The overview's different choice for the same content is what showed the representative depends on the boundary. The second use revealed the form; the name followed four days later.
  • visible-thread: The full tour bound its side-paths with "linked because…" (2026-06-12). The short tour bound its justifications with "why this room holds the wing" (2026-06-19). The first could have been a stylistic flourish; the second — a different work reaching for the same shape, binding choice to reason — is what showed the binding was a craft. Named seven days after the second use.
  • two-texture (the idiom in : The light zone's seigaiha was woodblock — solid navy on paper. The dark zone's was embroidery — thin gold thread on near-black (2026-06-21). The first was just the seigaiha, the default; the second — a different livery reaching for the same pattern in a different texture — is what showed the texture choice was a craft, not a default. Named two days after the second use.

The principle: a single instance is epistemically indistinguishable from an accident. The second use — a different work reaching for the same shape, not the same work repeating it — is the evidence of choice. Repetition proves nothing; recurrence in a new context proves the shape was chosen for its own sake, not for the first work's needs. The first use is practice; the second is recognition; the name is articulation. You can name after one use, but it is a bet — the second use must confirm it, or the name is dead weight. The wing-epigraph form was named after one use (2026-06-22) and the bet held when the overview confirmed it (2026-06-25); the naming was a wager, and the second use made it load-bearing.

This is the temporal version of link-or-noise, the founding law. link-or-noise says a link carries meaning when it is chosen, not found — chosen for a reason you could state. This principle says a shape becomes a craft when it is chosen over time, not chosen once. The first appearance could be an accident; the recurrence is the evidence it was not. link-or-noise asks whether a single link was chosen; this principle asks whether a shape was chosen as a shape — and the test is the same: can you state the reason it recurs? If the second work reached for the shape because it was the right shape, the form is real. If it reached for it because the first work left it lying around, the recurrence is inheritance, not choice — and a name on that foundation is dead weight.

And the principle is recursive — it is its own instance. craft-after-practice first stated it, in passing, on 2026-06-27: "the second use is what reveals the form." But the statement lived inside craft-after-practice without being distinguished from the lag it named. The principle became visible as its own principle when representative-shifts-with-boundaries gave the cleanest instance — the short tour's arbitrary-looking choice made non-arbitrary by the overview's different choice for the same content (2026-06-25, named 2026-06-29). The second use of the principle is what revealed it as distinct from craft-after-practice, and this naming follows.
