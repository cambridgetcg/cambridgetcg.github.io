2:Tab7,<p>What gathers here: what the act of pulling a memory out builds, and why that is different from what a map of knowledge builds. This room answers the door opened by <a href="/castle-gate/rooms/linking-thoughts">linking-thoughts</a>: if recalling sometimes beats deliberate linking, what is <a href="/castle-gate/words/retrieval-practice">retrieval-practice</a> actually building that a map is not?</p>
<h2>The answer, plainly</h2>
<p>A map is a picture of where things are. Recalling is the walk back to them. Practicing the walk builds something no picture can: the road itself.</p>
<ul><li>Recalling is not just linking in disguise. Karpicke &amp; Smith showed that   repeated recall kept improving durable memory even <em>after</em> studying and   elaborating had done all they could — while repeating the elaboration added   nothing more. Whatever recall builds, it is a separate thing.   (read 2026-06-10 — <a href="https://www.sciencedirect.com/science/article/abs/pii/S0749596X12000149" rel="noopener">Separate mnemonic effects of retrieval practice and   elaborative encoding, Journal of Memory and Language 2012</a>)</li><li>The leading explanation is the <em>episodic context account</em>: each time you   pull a memory out, you partly relive the moment you learned it and bind the   memory to the present moment too. The memory ends up reachable from more   starting points — recall builds <strong>access</strong>, where a map builds <strong>structure</strong>.   (read 2026-06-10 — <a href="https://learninglab.psych.purdue.edu/downloads/2014/2014_Karpicke_Lehman_Aue_PLM.pdf" rel="noopener">Karpicke, Lehman &amp; Aue, Retrieval-Based Learning: An   Episodic Context Account, 2014</a>)</li><li>The two are friends, in the right order. A 2023 review found that   elaborating <em>before</em> recall practice gives a boost, while elaborating   <em>during</em> recall is redundant — the two acts use overlapping mental work.   First connect, then practice the walk back.   (read 2026-06-10 — <a href="https://link.springer.com/article/10.1007/s10648-023-09784-8" rel="noopener">Combining Retrieval Practice with Elaborative Encoding:   Complementary or Redundant?, Educational Psychology Review 2023</a>)</li></ul>
<p>So the castle's own habit would be: build the room (linking), then later try to recall what the room says before re-reading it. The map shows where the treasure is; only walking the path keeps it reachable.</p>
