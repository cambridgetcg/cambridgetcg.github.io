2:T10b3,<p><a href="/castle-gate/rooms/correlated-witnesses">correlated-witnesses</a> left the reader counting only the overlap that was written down, while the load-bearing beam — a shared assumption nobody declared — stayed invisible. This room asks for a move that surfaces it. The honest answer is yes, with a sharp condition: the disagreement must be <em>genuine</em>, not staged.</p>
<p>The premise is real. When forecasters draw on overlapping information their estimates correlate, so averaging double-counts the common signal and apparent agreement overstates confidence — the <em>shared-information problem</em> (<a href="http://www.asapalley.com/uploads/4/7/5/0/47502723/palley_soll_2019_extracting_the_wisdom_of_crowds.pdf" rel="noopener">Palley &amp; Soll, read 2026-06-11</a>). Counting declared inputs misses exactly this correlation.</p>
<p>Two moves work. The first asks each person not only for their answer but to <em>predict what others will answer</em> — the meta-layer. When an answer is more common than the group predicted, that surplus flags a private signal the majority lacks; this <em>surprisingly popular</em> algorithm cut errors 21.3% versus majority vote across geography, medicine and art (<a href="https://phys.org/news/2017-01-scholars-method-harvesting-crowd-wisdom.html" rel="noopener">Prelec et al., read 2026-06-11</a>). The second builds a counter-case on the <em>opposite</em> assumption. Dialectical inquiry — two proposals on clashing premises, then synthesis — surfaced higher-quality assumptions than consensus (<a href="https://journals.aom.org/doi/10.5465/255859" rel="noopener">Schweiger, Sandberg &amp; Ragan, read 2026-06-11</a>), because forcing the opposite case drags the shared premise into the light.</p>
<p>But the provocation must be honest. Authentic dissent stimulated original thought and consideration of the other side; a role-played devil's advocate mostly produced <em>cognitive bolstering</em> of the original view — &quot;no role-playing technique stimulates divergent thinking as authentic dissent does&quot; (<a href="https://onlinelibrary.wiley.com/doi/abs/10.1002/ejsp.58" rel="noopener">Nemeth, Brown &amp; Rogers, read 2026-06-11</a>). A manufactured fight can entrench the very assumption it meant to expose.</p>
<h2>What stays uncertain</h2>
<p>uncertain: the move can backfire. The same dependence that hides shared assumptions means social interaction often <em>reduces</em> crowd accuracy — letting people see each other's estimates correlates their errors instead of cancelling them, so provoking talk helps only if it injects independent signal, not if it manufactures false consensus around the shared premise (<a href="https://pmc.ncbi.nlm.nih.gov/articles/PMC5938592/" rel="noopener">wisdom-of-crowds, read 2026-06-11</a>). And where the overlap is a deep <em>framework</em> assumption, more argument may surface a clash it cannot adjudicate or even cleanly name — deep disagreement hits bedrock (<a href="https://philarchive.org/archive/MELFDD" rel="noopener">Fogelin, read 2026-06-11</a>). The cruelest case: a hidden common cause tends to make agents <em>agree</em>, so the overlap hides in consensus, not conflict — there is no disagreement to provoke (<a href="https://arxiv.org/abs/2605.00844" rel="noopener">AI-forecasting, read 2026-06-11</a>).</p>
