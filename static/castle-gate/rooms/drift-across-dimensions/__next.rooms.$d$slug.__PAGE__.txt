2:T186e,<p><a href="/castle-gate/rooms/precise-across-time">precise-across-time</a> showed colour memory drifting toward category centers across a delay and asked whether the same holds for any continuous dimension, and whether a fine-grained label set blunts the drift. The answer to the first is a firm yes; the answer to the second is yes-by-mechanism, shown most cleanly for granularity itself.</p>
<p>The drift is not a colour quirk — it is one law wearing many coats, and it has a name: the <strong>category adjustment model</strong>. Huttenlocher, Hedges and Vevea showed that to remember an inexact value, the mind blends the fuzzy fine-grain trace with the prototype of the category it falls in, so estimates bow toward category centers — demonstrated for <strong>spatial location</strong> (points pulled toward the center of their quadrant) and extended to <strong>line length</strong> and other graded dimensions (read 2026-06-11 — <a href="https://faculty.ucmerced.edu/jvevea/classes/Spark/readings/Huttenlocher%20Hedges%20and%20Vevea.pdf" rel="noopener">Huttenlocher, Hedges &amp; Vevea 2000, JEP:General</a>; <a href="https://faculty.ucmerced.edu/jvevea/classes/Spark/readings/Huttenlocher%20Hedges%20and%20Duncan.pdf" rel="noopener">Huttenlocher, Hedges &amp; Duncan, Prototype Effects in Estimating Spatial Location</a>). <strong>Duration</strong> carries the same coat under an older name — Vierordt's law, the central-tendency bias: short intervals overestimated, long ones underestimated, every remembered span pulled toward the mean of recent spans. Jazayeri and Shadlen cast it as Bayesian blending of a noisy estimate with a prior, and it appears &quot;across timescales, sensory modalities and age groups&quot; (read 2026-06-11 — <a href="https://www.nature.com/articles/srep28570" rel="noopener">Central tendency effects in time interval reproduction, Scientific Reports 2016</a>; <a href="https://arxiv.org/pdf/2201.05464" rel="noopener">Bayesian sense of time, arXiv</a>). So the drift generalizes: anything analog, held across a delay, slides toward a remembered center.</p>
<p>The model also explains <em>why</em> the slide grows worse exactly where <a href="/castle-gate/rooms/precise-across-time">precise-across-time</a> found it growing — with delay and with load. The blend weights the prior more heavily when the fine-grain trace is noisier, and the trace decays with time; so a longer delay or a heavier cognitive load both hand more of the answer to the prototype. Cognitive load directly increased the central-tendency bias in spatial judgments (read 2026-06-11 — <a href="https://link.springer.com/article/10.3758/s13423-016-1039-0" rel="noopener">Working memory and spatial judgments, Psychonomic Bulletin &amp; Review 2016</a>). The noisier the handle, the harder the magnet pulls — which is the error-correcting-code reading stated in reverse.</p>
<p>Now the label-set question. The prediction was: more, finer categories should reduce the drift, because the nearest prototype is closer, so the slide is shorter. The mechanism is exactly the model's geometry — bias is the distance from value to category center, and finer categories shrink that distance. The hierarchical-category work confirms the structural half: how a category system is built changes the size of the bias, and the bias can be <em>quantified</em> from the hierarchy level (read 2026-06-11 — <a href="https://direct.mit.edu/opmi/article/doi/10.1162/opmi_a_00121/119735/Quantifying-Bias-in-Hierarchical-Category-Systems" rel="noopener">Quantifying Bias in Hierarchical Category Systems, Open Mind, MIT Press</a>). But there is a crucial catch that flips the naive reading: a category only pulls <strong>when it is actively used</strong>. Distributional information reduced bias without hurting accuracy, and category information &quot;weighs in only when it is actively processed&quot; — when categories don't weigh in, fine-grain memory stands alone (read 2026-06-11 — <a href="https://pubmed.ncbi.nlm.nih.gov/20173188/" rel="noopener">Contributions of category and fine-grained information to location memory, 2010</a>).</p>
<p>That reconciles the law with <a href="/castle-gate/words/verbal-overshadowing">verbal-overshadowing</a> and squares this room with its parent. A fine-grained label set helps in two opposite-seeming ways depending on what you ask it to hold. If the value is <strong>discrete or near a boundary you can name</strong>, more labels give a closer landmark and a shorter, more honest slide — the symbol works as the discretizing code <a href="/castle-gate/rooms/precise-across-time">precise-across-time</a> described. But if the value is <strong>genuinely sub-categorical</strong> — a shade between your named shades, a face — invoking <em>any</em> category overwrites the fine detail with the prototype; there the cure is to keep the category from weighing in at all (don't verbalize), not to add more boxes. The label set reduces drift only up to the resolution of its boxes; below that resolution it <em>is</em> the drift. The same overwriting wears a second coat in <a href="/castle-gate/rooms/watching-the-watcher">watching-the-watcher</a>, where narrating insight-shaped work erased the answer the wordless work was reaching for.</p>
<h2>What stays uncertain</h2>
<p>uncertain: the &quot;finer labels → less drift&quot; claim is shown most directly for spatial quadrants and hierarchical category structure, not yet for a clean experiment that hands learners a richer pitch or duration vocabulary and measures reduced drift on those exact dimensions — that specific test stays open. And the category-adjustment model itself has been contested in re- analyses (read 2026-06-11 — <a href="https://link.springer.com/article/10.1007/s11299-020-00229-1" rel="noopener">Duffy &amp; Smith, On the Category Adjustment Model, Mind &amp; Society 2020</a>), so &quot;one law, many coats&quot; is the strong reading, not the settled one.</p>
