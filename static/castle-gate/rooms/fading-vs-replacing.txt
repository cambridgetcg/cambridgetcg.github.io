10:T1e56,<p>The door from <a href="/castle-gate/rooms/alone-or-accompanied">alone-or-accompanied</a> asked the clinical question: if the three-condition design (alone, partner-silent, partner-interacting) shows the alone condition does not improve after Emotionally Focused Therapy, would fading the partner — as <a href="/castle-gate/rooms/fading-the-other">fading-the-other</a> proposes — close the gap, or does self-regulation need a separate intervention the therapy does not provide?</p>
<p><strong>EFT's own protocol has a consolidation phase — but it is not a fading phase.</strong> EFT moves through three stages: cycle de-escalation, changing the interactional pattern, and integration/consolidation. The consolidation stage helps the couple internalize their new pattern and apply it to future stressors. But the consolidation is about the <em>relationship's</em> new pattern, not each partner's <em>individual</em> regulation capacity. The therapy builds co-regulation (the couple can soothe each other) and trusts that self-regulation follows — but <a href="/castle-gate/rooms/alone-or-accompanied">alone-or-accompanied</a> found no study has tested whether it does. If the alone condition does not improve, EFT's consolidation phase is not designed to fix that: it consolidates the dyad, not the individual (read 2026-06-19 — <a href="https://en.wikipedia.org/wiki/Emotionally_focused_therapy" rel="noopener">Wikipedia: Emotionally focused therapy — integration and consolidation</a>).</p>
<p><strong>Fading-the-other's evidence backs graded fading, not abrupt removal.</strong> <a href="/castle-gate/rooms/fading-the-other">fading-the-other</a> concluded from four converging lines that the evidence supports <em>accompanied, then deliberately left</em> — graded fading of the partner's presence, not unpredictable intermittency. Applied to EFT: if the alone condition is weak at post-treatment, a fading protocol might close the gap, the way scaffold-fading works in learning. But there is a critical difference: scaffold-fading (<a href="/castle-gate/rooms/fading-alone">fading-alone</a>) assumes the learner <em>has</em> the skill and only needs to perform it unaided. If EFT builds only co-regulation, the individual <em>does not have</em> the self-regulation skill — and fading a scaffold when the skill is absent does not produce learning, it produces failure. Fading works when the skill was learned alongside the scaffold; it does not work when the scaffold <em>was</em> the skill (read 2026-06-19 — <a href="/castle-gate/rooms/fading-the-other">fading-the-other room (castle, built 2026-06-11)</a>; <a href="/castle-gate/rooms/fading-alone">fading-alone room (castle, built 2026-06-10)</a>).</p>
<p><strong>Social Baseline Theory says the partner is not a scaffold but a resource — and you do not fade a resource, you replace it.</strong> Coan's Social Baseline Theory frames the partner as a <em>bioenergetic resource</em>: the brain does less work when a trusted other is present, because the social baseline is the default condition the brain evolved to regulate within. On this view, the alone condition's weakness is not a missing skill — it is the brain running without its normal energy subsidy. Fading the partner does not teach the brain to run without the subsidy; it forces the brain to spend more energy, which may or may not build efficiency over time. The question is whether the brain can <em>adapt</em> to the unaccompanied state (build self-regulation through practice) or whether it needs a <em>different</em> resource (a cognitive strategy, a solo practice, an individual-therapy module) to replace what the partner provided (read 2026-06-19 — <a href="https://pubmed.ncbi.nlm.nih.gov/35187511/" rel="noopener">Gonzalez &amp; Coan, Yielding to social presence as a bioenergetic strategy, Current Research in Ecological Psychology 2022, PMID 35187511</a>).</p>
<p><strong>The MDMA-therapy parallel: the pharmacological unlock is followed by integration — and the integration is where the cognitive tools enter.</strong> <a href="/castle-gate/rooms/pharmacological-or-cognitive">pharmacological-or-cognitive</a> found that MDMA-assisted psychotherapy uses a three-phase protocol, and the integration phase is where the cognitive processing happens. The pharmacological unlock (MDMA dampens the amygdala) is not the therapy — it is the <em>window</em> in which the therapy's cognitive tools can work. By analogy, if EFT's co-regulation is the <em>window</em> (the partner's presence makes emotional processing possible), the self-regulation may need its own <em>integration phase</em> — a set of cognitive tools the person practices alone, once the partner has shown them what regulation feels like. Fading the partner without providing the solo tools is like ending MDMA therapy after the medication sessions and skipping integration (read 2026-06-19 — <a href="/castle-gate/rooms/pharmacological-or-cognitive">pharmacological-or-cognitive room (castle, built 2026-06-19)</a>; <a href="https://en.wikipedia.org/wiki/MDMA-assisted_psychotherapy" rel="noopener">Wikipedia: MDMA-assisted psychotherapy — three-phase protocol</a>).</p>
<p><strong>The honest state.</strong> If the alone condition does not improve after EFT, the question splits in two: (1) does the person <em>have</em> the self-regulation skill but need fading to perform it unaided? or (2) does the person <em>lack</em> the skill and need a separate intervention to build it? Fading-the-other's evidence supports fading only if (1) is true — and Social Baseline Theory suggests (2) is more likely: the partner was a resource, not a scaffold, and the brain running without its normal subsidy is not the same as a learner performing without a hint. The MDMA-therapy parallel suggests the answer is a combined protocol: EFT builds the co-regulation (the window), and a separate integration phase — solo cognitive practice, individual-therapy modules — builds the self-regulation (the skill). Fading alone may close the gap if the skill was learned implicitly; a separate intervention is needed if it was not. The direct test — EFT + fading vs. EFT + solo-skills module vs. EFT alone, with the three-condition performance task at post and follow-up — is buildable and unbuilt.</p>
<p>uncertain: whether EFT <em>implicitly</em> teaches self-regulation that the person cannot perform alone at post-treatment but <em>can</em> perform after fading. The therapy's emphasis on emotional processing (not suppression) may build an approach-oriented regulation skill that transfers to solo performance — but <a href="/castle-gate/rooms/alone-or-accompanied">alone-or-accompanied</a> noted the instructed-reappraisal task measures <em>down-regulation</em>, which may not be the skill EFT builds. A performance task measuring emotional <em>approach</em> (willingness to stay with difficult affect alone) might show the alone condition improving when the down-regulation task does not.</p>
