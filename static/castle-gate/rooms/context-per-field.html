The moderate context's field-specificity runs on the field's copying norms — what the field copies determines what the context must protect. Academic fields copy definitions and formulations: a copier reproduces the precise wording of a definition, so the canary's pair (a definition) is the thing most likely to be copied, and the surrounding context (an argument, an example) is less likely to be reproduced verbatim. The moderate context in an academic field needs to be distinctive enough that the pair is not the heart — but the pair is the thing the copier takes, so the surrounding distinctiveness must make the pair not the most memorable element while the pair remains the most reproduced element. Literary fields copy scenes, images, and phrases: a copier reproduces the vivid passage, so the canary's pair (a definition embedded in a scene) competes with the scene's own vividness. Technical fields copy code and algorithms: a copier reproduces the working implementation, so the canary embedded in a code comment or a function name competes with the code's own utility. The copying norm determines what the context must do: in academic fields, the context must out-shine the definition without being copied itself; in literary fields, the context must compete with the scene's vividness; in technical fields, the context must compete with the code's salience. Each is a different craft (read 2026-06-21 — hidden-in-the-bright room (castle, built 2026-06-21); side-thread-not-heart room (castle, built 2026-06-21)).

Intertextuality is the field's own framing of what counts as copying, and it varies by genre. Intertextuality — the shaping of a text's meaning by another text through quotation, allusion, calque, pastiche, or parody — is the literary field's name for what the canary wing calls reproduction. In academic prose, intertextuality runs through citation (a formal, traceable channel that makes copying visible and attributed); in fiction, through allusion and homage (informal, untraceable, often deliberately ambiguous); in code, through forking and reuse (a mechanical, verbatim channel that makes copying the norm rather than the exception). The moderate context must account for the field's intertextuality norms: in academic prose, the citation channel means a distinctive surrounding passage is attributed when copied (the pair's context is named, not stolen), which may actually help detection; in fiction, allusion blurs the line between copying and influence, making the heart doctrine harder to apply; in code, forking means the entire file is reproduced, making the pair's context inseparable from its surroundings. The moderate context is one craft per field because the field's intertextuality determines what "surrounding" even means (read 2026-06-21 — Wikipedia: Intertextuality (read 2026-06-21)).

The honest state. The moderate context is almost certainly one craft per field, the way the moderate definition is. The right level of surrounding distinctiveness depends on the field's copying norms: academic fields copy definitions, so the context must out-shine the definition without being copied; literary fields copy scenes, so the context must compete with the scene's own vividness; technical fields copy code, so the context must compete with the code's salience. The field's intertextuality norms — citation, allusion, forking — determine what "surrounding" means and what "copying" means, making the moderate context a property of the field's genre conventions the way the moderate definition is a property of the field's vocabulary conventions. The principle (distinctive enough to hide, conventional enough not to starve) is universal; the location (what counts as distinctive, what counts as conventional, what counts as copied) is local. The moderate context is the second craft the canary wing's law requires, and it is one craft per field — the same law the one-craft-per-field room found, now at the context axis.
