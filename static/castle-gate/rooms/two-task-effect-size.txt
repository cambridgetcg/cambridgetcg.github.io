10:T1f48,<p>The door from <a href="/castle-gate/rooms/minimum-class-size">minimum-class-size</a> asked the practical question: the class-level inverted diagnostic (two unrewarded tasks, read the gap difference) needs an effect size to be powered, but the only available benchmark (d = .28–.40) is the reward-undermining effect — the gap between a <em>rewarded</em> and an <em>unrewarded</em> task, not between two <em>unrewarded</em> tasks of different <em>value</em>. The question's own uncertain note flagged that the hidden-vs-absent value gap may be smaller than the reward-vs-no-reward gap. Could the simplest version (two tasks, no reveal, class of 30) run first to estimate the gap, and would that estimate justify the four-cell reveal study?</p>
<p><strong>The reward-undermining benchmark is the wrong comparison — the inverted diagnostic's gap is between two unrewarded tasks, not rewarded vs. unrewarded.</strong> The Deci, Koestner &amp; Ryan (1999) meta-analysis found d = -0.40, -0.36, and -0.28 for engagement-, completion-, and performance-contingent rewards undermining free-choice intrinsic motivation. But the inverted diagnostic compares two <em>unrewarded</em> tasks that differ in <em>value</em> (one has hidden value, one has absent value), not a rewarded task against an unrewarded one. The reward-undermining effect is the gap produced by <em>adding</em> a reward (which crowds out intrinsic motivation); the inverted diagnostic's gap is produced by <em>the task's own value</em> (which should sustain intrinsic motivation where it exists and fail to sustain it where it does not). These are different mechanisms: reward undermining is a <em>suppression</em> of existing intrinsic motivation; the value gap is a <em>difference</em> in whether intrinsic motivation takes hold at all. There is no published effect size for the latter, because no study has run the two-unrewarded-tasks-of-different-value design (read 2026-06-19 — <a href="https://pubmed.ncbi.nlm.nih.gov/10589297/" rel="noopener">Deci, Koestner &amp; Ryan, Psychological Bulletin 1999, PMID 10589297</a>; <a href="/castle-gate/rooms/minimum-class-size">minimum-class-size room — the meta-analytic benchmarks (castle, built 2026-06-19)</a>).</p>
<p><strong>The free-choice paradigm has measured task-interest differences without rewards — and the gaps are real but small.</strong> Deci's original 1971 study measured free-choice time on a puzzle task <em>without</em> any reward manipulation, comparing participants who found the task interesting to those who did not — the free-choice measure was the dependent variable for intrinsic motivation, and it varied with reported interest. Self-determination theory's broader literature shows that task characteristics (autonomy support, competence feedback, relevance) produce free-choice differences in the d = 0.20–0.50 range — but these are <em>intervention</em> effects (an experimenter manipulates the task's framing), not <em>intrinsic value</em> effects (the task itself carries or lacks value). The closest existing design to the inverted diagnostic is the &quot;interesting vs. boring task&quot; free-choice comparison, where participants given a boring task show less free-choice engagement than those given an interesting one — but &quot;boring&quot; is not the same as &quot;absent value,&quot; and &quot;interesting&quot; is not the same as &quot;hidden value.&quot; The gap between an interesting and a boring task is likely larger than the gap between a hidden-value and an absent-value task, because the latter two may <em>appear</em> equally interesting (the value is hidden) (read 2026-06-19 — <a href="https://en.wikipedia.org/wiki/Self-determination_theory" rel="noopener">Wikipedia: Self-determination theory — the free-choice paradigm (read 2026-06-19)</a>; <a href="/castle-gate/rooms/inverted-diagnostic">inverted-diagnostic room — the two-task design (castle, built 2026-06-19)</a>).</p>
<p><strong>The simplest version is the right first step — and its honest purpose is to estimate, not to confirm.</strong> Running the two-task, no-reveal design with a class of 30 is the cheapest way to get an effect-size estimate for the hidden-vs-absent value gap. The within-subject design (each learner does both tasks, counterbalanced) gives the power of ~50–60 between-subjects, so a class of 30 can detect d_z ≈ 0.50 at α = .05, power = .80. If the observed gap difference is in the d = 0.30–0.50 range, the four-cell reveal study is justified at a feasible class size (50–70 for d = 0.28, 25–30 for d = 0.40). If the observed gap is smaller (d &lt; 0.20), the reveal study would need 100+ learners per cell — likely infeasible for a classroom design, and the diagnostic's noise floor may be above the signal. The simplest version's purpose is not to confirm the diagnostic but to <em>measure its signal strength</em> before investing in the four-cell design (read 2026-06-19 — <a href="/castle-gate/rooms/minimum-class-size">minimum-class-size room — the power calculations (castle, built 2026-06-19)</a>; <a href="/castle-gate/rooms/class-gap-diagnostic">class-gap-diagnostic room — the within-learner control (castle, built 2026-06-19)</a>).</p>
<p><strong>The prediction: the gap will be smaller than the reward-undermining benchmark, but not necessarily too small to detect.</strong> The hidden-value task carries real value the learner has not yet perceived; the absent-value task carries none. The free-choice gap between them reflects the difference in <em>whether intrinsic motivation takes hold</em> — and SDT predicts that even hidden value produces some autonomous engagement (the task is genuinely interesting, even if the learner does not know why), while absent value produces only controlled engagement at best. The gap should be smaller than the reward-undermining effect (which suppresses <em>existing</em> intrinsic motivation, a stronger force than the <em>presence vs. absence</em> of value), but it should not be zero — the task characteristics that produce free-choice differences (autonomy, competence, relevance) are exactly what hidden value provides and absent value lacks. The honest prediction: d ≈ 0.20–0.35, detectable at a class of 30–50, and justifying the reveal study at the lower end of the feasible range (read 2026-06-19 — <a href="/castle-gate/rooms/willingness-persistence-gap">willingness-persistence-gap room — the original diagnostic (castle, built 2026-06-19)</a>; <a href="/castle-gate/rooms/revealing-vs-creating">revealing-vs-creating room — warmth as lens (castle, built 2026-06-19)</a>).</p>

The reward-undermining benchmark (d = .28–.40) is the wrong comparison: it measures the gap between rewarded and unrewarded tasks, not between two unrewarded tasks of different value, and the latter is predicted to be smaller (reward undermining suppresses existing motivation; the value gap measures whether motivation takes hold at all). The prediction is d ≈ 0.20–0.35, detectable at a class of 30–50, and justifying the reveal study at the feasible range's lower end. If the gap is smaller than d = 0.20, the four-cell reveal study would need 100+ learners per cell and may be infeasible as a classroom design — the diagnostic's signal would be below its noise floor. No study has run this two-task design; the effect-size estimate does not exist.</p>
