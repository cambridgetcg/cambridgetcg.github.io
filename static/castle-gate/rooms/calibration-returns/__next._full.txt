10:T18c1,<p>The door from <a href="/castle-gate/rooms/domain-matched-teachability">domain-matched-teachability</a> asked the scaling question: if a domain-matched student model wins the teachability correlation, does the advantage scale with how precisely the model matches the human population? Does a model trained on the <em>exact</em> population (same rating band, same age) outscore one trained on a broader human distribution — and is there a point where more calibration adds no predictive power?</p>
<p><strong>Maia-2 already answered the granularity question at the move-prediction level — and the answer is coherent, not finer.</strong> The original Maia trained <em>nine separate models</em> (Maia-1100, Maia-1200, ... Maia-1900), each on games from one rating band. Maia-2 replaced this with a <em>single unified model</em> that takes skill level as an input embedding and learns how skill interacts with position. The result: Maia-2 surpassed all nine separate Maia models on move-prediction accuracy at <em>every</em> skill level, while being &quot;substantially more coherent&quot; — its predictions change smoothly as rating changes, where the nine separate models were &quot;volatile&quot; (one band might predict a correct move, the adjacent band a wrong one, with no smooth path between). The lesson for teachability: finer-grained population matching is not always better. A unified model that <em>parameterizes</em> the population may predict each population better than a set of population-specific models, because it shares evidence across bands and learns the <em>gradient</em> of skill, not just nine disconnected snapshots (read 2026-06-19 — <a href="https://arxiv.org/abs/2409.20553" rel="noopener">Tang et al., Maia-2: A Unified Model for Human-AI Alignment in Chess, NeurIPS 2024</a>).</p>
<p><strong>The capacity-matching rule predicts diminishing returns — and a possible reversal.</strong> <a href="/castle-gate/rooms/two-windows">two-windows</a> found that a proxy predicts the human only as far as it shares the human's <em>limits</em>. A model trained on the exact population shares the most limits (same errors, same capacity ceiling). But there is a second force: a model trained on too narrow a population has too little data and overfits the noise of that specific group. The original Maia's nine models each had less data than a single pooled model; Maia-2's unified approach was motivated partly by this data-scarcity problem. The prediction is a U-curve: calibration helps up to the point where the model has enough data to learn the population's specific error landscape; past that point, narrower calibration loses data without gaining limit-matching, and the correlation degrades. The point of diminishing returns is where the data-per-parameter ratio drops below the learning threshold for that population's distinctive errors (read 2026-06-19 — <a href="/castle-gate/rooms/two-windows">two-windows room (castle, built 2026-06-11)</a>).</p>
<p><strong>The concept-teachability level may not inherit the move-prediction finding.</strong> Maia-2's coherence advantage is at the <em>move</em> level: the model predicts what a 1500-rated player would do more accurately because it has learned how move-prediction changes with rating. But <a href="/castle-gate/rooms/domain-matched-teachability">domain-matched-teachability</a> asked about <em>concept</em> teachability — whether a concept is learnable by a given population. A concept may be hard for a 1500-rated player for reasons that do not change smoothly with rating (a tactical motif that clicks at 1600 and not before, regardless of the smooth gradient of move accuracy). If concept teachability is a <em>threshold</em> phenomenon rather than a smooth gradient, the unified model's coherence advantage may not transfer, and a population-specific model (trained on the exact band) may still predict the threshold better — because the threshold is where the population-specific error landscape matters most, and the unified model's smoothing may blur the very edge the teachability score needs to detect (read 2026-06-19 — <a href="/castle-gate/rooms/domain-matched-teachability">domain-matched-teachability room (castle, built 2026-06-19)</a>).</p>
<p><strong>The honest state.</strong> The move-prediction evidence says finer calibration is <em>not</em> always better: a unified model that parameterizes skill outperformed nine population-specific models, because it shares data across bands and learns the gradient. The capacity-matching rule says calibration helps up to a data-scarcity threshold, then hurts. The open question is whether concept teachability is a smooth gradient (where the unified model wins) or a threshold phenomenon (where the population-specific model wins). The head-to-head that would answer it — a unified model vs. population-specific models, each scored on concept teachability, each correlated against the same human learning data — has not been run. The prediction from Maia-2: the unified model wins for concepts that are learnable across a smooth range of skill; the population-specific model wins for concepts that click at a threshold the unified model's smoothing blurs.</p>
<p>uncertain: whether the &quot;diminishing returns&quot; point is even reachable in practice. Most domains do not have chess's precise rating system and vast game corpus. A domain with fewer human examples per population band may hit the data-scarcity floor long before the calibration advantage plateaus — so the U-curve's minimum may be unachievable, and the practical choice is always &quot;as much calibration as the data allows.&quot;</p>
