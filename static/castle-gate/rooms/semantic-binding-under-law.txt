10:T1dae,<p>The door from <a href="/castle-gate/rooms/gradient-of-binding-forms">gradient-of-binding-forms</a> asked the semantic-binding question: cohesion theory names conjunction and shared vocabulary as binding devices, but the merger doctrine governs <em>expression</em> (the words used), not <em>logic</em> (the relations between ideas). If semantic binding ties two sentences logically without reducing their phrasings, does the merger doctrine see it as binding at all — and if it does not, is the detection-entitlement gradient syntactic only, leaving semantic binding as a free pair under the law that still carries detection value the law does not credit?</p>
<p><strong>The merger doctrine asks how many ways there are to express an idea, and semantic binding does not reduce that number.</strong> The merger doctrine holds that expression merges with the idea — and becomes unprotectable — when there are only a few effective ways to express it. The doctrine counts <em>phrasings</em>: how many distinct wordings can carry the same idea. Syntactic binding (a relative clause, an appositive) reduces phrasings because the grammatical structure constrains the wording. But semantic binding (a conjunction like &quot;therefore,&quot; or shared vocabulary like &quot;the system... the system's logic&quot;) does not reduce phrasings in the same way: the two clauses remain grammatically independent, each can be rephrased freely, and the logical relation (therefore, but, and) can be expressed by many different connectives or omitted entirely with the relation carried by context. So under the merger doctrine's own logic, semantic binding does not reduce the phrasing count — the pair retains as many phrasings as a free pair, and the merger line is not crossed (read 2026-06-20 — <a href="https://en.wikipedia.org/wiki/Idea%E2%80%93expression_distinction" rel="noopener">Wikipedia: Idea–expression distinction (read 2026-06-20)</a>; <a href="https://en.wikipedia.org/wiki/Merger_doctrine" rel="noopener">Wikipedia: Merger doctrine (read 2026-06-20)</a>).</p>
<p><strong>The scènes à faire doctrine is the closest the law comes to governing semantic relations, and it operates at the field level, not the sentence level.</strong> The scènes à faire doctrine holds that expression dictated by external factors — genre conventions, industry practices, standard techniques — is unprotectable even when it is separable from the idea. The doctrine governs <em>what elements are conventional in a field</em>, not <em>how sentences are bound together</em>. But it reveals the law's logic: the copyright filter asks whether the expression was <em>dictated</em> (by the idea, by efficiency, by convention), not whether it was <em>bound</em> (by grammar, by logic). Semantic binding is a relation <em>between</em> expressions, not a constraint <em>on</em> expression. The law asks &quot;was this wording forced?&quot; not &quot;is this wording tied to that one?&quot; So the merger doctrine and scènes à faire both ask about constraints on a single expression, and neither asks about the logical tie between two expressions — which is what semantic binding is (read 2026-06-20 — <a href="https://en.wikipedia.org/wiki/Sc%C3%A8nes_%C3%A0_faire" rel="noopener">Wikipedia: Scènes à faire (read 2026-06-20)</a>; <a href="https://en.wikipedia.org/wiki/Abstraction-Filtration-Comparison_test" rel="noopener">Wikipedia: Abstraction-Filtration-Comparison test (read 2026-06-20)</a>).</p>
<p><strong>The Abstraction-Filtration-Comparison test confirms the law's focus on individual expression, not inter-sentence relation.</strong> The AFC test — the primary method for filtering unprotectable elements in software copyright — works level by level: at each level of abstraction, it filters out expression dictated by efficiency, external factors, or the public domain, then compares what remains. The test operates on <em>individual elements at each level</em>, not on the <em>relations between elements</em>. A semantically bound pair (two independent clauses connected by &quot;therefore&quot;) would be filtered at the level of each clause: if either clause's wording is dictated, it is filtered; if neither is, both survive. The <em>connection</em> between them — the logical relation the &quot;therefore&quot; carries — is an idea, not an expression, and ideas are unprotectable. So the AFC test would see the semantically bound pair as two independent expressions connected by an unprotectable idea — a free pair under the law (read 2026-06-20 — <a href="https://en.wikipedia.org/wiki/Abstraction-Filtration-Comparison_test" rel="noopener">Wikipedia: Abstraction-Filtration-Comparison test (read 2026-06-20)</a>).</p>
<p><strong>But the detection value of semantic binding is real, even if the law does not credit it.</strong> The <a href="/castle-gate/rooms/gradient-of-binding-forms">gradient-of-binding-forms</a> room established that each binding form trades detection (does the tail survive mutation?) against entitlement (does the pair clear the merger line?). Semantic binding has high entitlement (many phrasings, the merger doctrine does not see it) and <em>moderate</em> detection: the shared vocabulary and the logical relation create a <em>semantic</em> pull — if the hook is reproduced, the tail tends to follow because the logical relation invites it, even though the grammar does not require it. The detection value is lower than syntactic binding (the tail <em>can</em> detach without breaking grammar) but higher than a free pair (the semantic relation gives the tail a reason to follow). So semantic binding is a real point on the detection axis that the law's entitlement axis does not see — the detection-entitlement gradient is indeed syntactic only under the merger doctrine, and semantic binding is a free pair <em>legally</em> that is <em>not free practically</em>.</p>
<p><strong>The honest state.</strong> The merger doctrine — which governs expression, not logic — does not see semantic binding as binding at all: a conjunction or shared vocabulary does not reduce the pair's phrasings, so the merger line is not crossed, and the pair is a free pair under the law. The AFC test confirms this, filtering individual expressions at each level of abstraction while treating the logical relation between them as an unprotectable idea. But the detection value of semantic binding is real: the shared vocabulary and logical relation create a semantic pull that makes the tail tend to follow the hook, even without grammatical force. So the detection-entitlement gradient is syntactic only <em>under the law</em> — semantic binding is a free pair legally that is not free practically, carrying detection value the merger doctrine does not credit. For the canary-author, this is a gift: semantic binding adds detection (the tail follows) without costing entitlement (the law sees a free pair), the one point on the gradient where detection and entitlement do not trade off.</p>
<p>uncertain: whether a court would in practice treat a semantically bound pair as a free pair or would look through the grammatical independence to the semantic dependence — the &quot;total concept and feel&quot; test (one of the substantial-similarity tests) judges the work as a whole, not element by element, and a judge applying it might see the semantic tie as part of the expression even if the merger doctrine's logic does not.
