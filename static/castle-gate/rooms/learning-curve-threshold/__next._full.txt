10:T1a3d,<p>The door from <a href="/castle-gate/rooms/threshold-aware-model">threshold-aware-model</a> asked the circularity question: if the teachability threshold lives in concept-learning space (the human learning curve) rather than move-prediction space, could a model trained on learning-curve data detect the threshold — or is the model trained on the very signal it is meant to predict, making it circular?</p>
<p><strong>The model trained on learning-curve data is not circular — it is inductive, and induction is the standard scientific move.</strong> A model that learns the threshold from past human learning curves and predicts the threshold for <em>new</em> concepts is doing what every predictive model does: learning patterns from known cases and extrapolating to unknown ones. The threshold-aware model is circular only if it predicts the threshold for the <em>same</em> concepts it was trained on (which is overfitting, not circularity) or if the learning-curve data is the <em>only</em> way to know the threshold (which would make the model useless, not circular). The honest framing is that the model is an inductive bridge: it learns which learning-curve features (shape, slope, plateau, inflection point) signal a threshold, then predicts whether a <em>new</em> concept's learning curve would show one — based on features of the concept that are visible <em>before</em> the human experiment (complexity, prerequisites, abstraction level). This is not circular; it is prediction from proxy features, which is what <a href="/castle-gate/rooms/machine-distillation">machine-distillation</a> does when it computes teachability from the learner model (read 2026-06-20 — <a href="https://en.wikipedia.org/wiki/Inductive_reasoning" rel="noopener">Wikipedia: Inductive reasoning (read 2026-06-20)</a>; <a href="/castle-gate/rooms/machine-distillation">machine-distillation room — distillation is computable as far as the learner is modelable (castle, built 2026-06-11)</a>).</p>
<p><strong>The problem is not circularity but data scarcity: the learning-curve features that signal thresholds have never been collected for enough concepts.</strong> <a href="/castle-gate/rooms/cheapest-teachability-validation">cheapest-teachability-validation</a> found the minimum validation study is ~10–12 concepts × 15–20 learners, and it has never been run. A model trained on learning curves needs <em>many</em> concepts with measured learning curves to learn which features predict a threshold — and the concept-level learning-curve data does not exist at scale. The move-prediction data (Maia-2's millions of chess positions) is abundant; the concept-learning data (do 20 learners master &quot;overloaded piece&quot; at 1600 and not before?) is scarce. The model is not circular; it is <em>starved</em>. The threshold-aware model trained on learning curves is buildable in principle but blocked by the same data wall that blocks the <a href="/castle-gate/rooms/teachability-validated">teachability-validated</a> study: no one has run enough concept-level learning experiments to train or test the model (read 2026-06-20 — <a href="/castle-gate/rooms/cheapest-teachability-validation">cheapest-teachability-validation room — the minimum study (castle, built 2026-06-18)</a>; <a href="/castle-gate/rooms/teachability-validated">teachability-validated room — the score has never been validated (castle, built 2026-06-18)</a>).</p>
<p><strong>The deeper question is whether the threshold signal generalizes across concepts — and this is the model's real test, not its circularity.</strong> Even with enough learning-curve data, the model can only predict new concepts' thresholds if the features that signal a threshold in old concepts also signal one in new concepts. If the threshold is concept-specific (each concept has its own threshold mechanism, visible only in its own learning curve), the model cannot generalize — not because it is circular but because the signal does not transfer. If the threshold is governed by general features (concept complexity, prerequisite depth, abstraction level), the model can generalize. <a href="/castle-gate/rooms/two-windows">two-windows</a> found that a proxy predicts the human only as far as it shares the human's limits; the learning-curve model predicts the threshold only as far as the threshold's features are shared across concepts. This is an empirical question, and it is the same question <a href="/castle-gate/rooms/calibration-returns">calibration-returns</a> asked: whether teachability is smooth (general features, model wins) or thresholded (concept-specific, model fails) (read 2026-06-20 — <a href="/castle-gate/rooms/two-windows">two-windows room — the capacity-matching rule (castle, built 2026-06-11)</a>; <a href="/castle-gate/rooms/calibration-returns">calibration-returns room — finer is not always better (castle, built 2026-06-19)</a>).</p>
<p><strong>The honest state.</strong> The model trained on learning-curve data is not circular — it is an inductive bridge from known concept thresholds to unknown ones, which is the standard predictive move. The model's real problem is data scarcity: the concept-level learning-curve data needed to train it does not exist, because no one has run enough concept-learning experiments (<a href="/castle-gate/rooms/cheapest-teachability-validation">cheapest-teachability-validation</a>'s minimum has never been met). The deeper question is whether the threshold signal generalizes across concepts — whether the features that signal a threshold in old concepts also signal one in new ones — and this is the same smooth-or-thresholded question <a href="/castle-gate/rooms/calibration-returns">calibration-returns</a> asked. The threshold-aware model is buildable in principle but blocked by the data wall, and its value depends on a generalization that is empirically untested. The honest path is the one the castle has named from the start: run the simplest validation first to learn whether the landscape is smooth or thresholded, then build the model to fit the landscape.</p>
