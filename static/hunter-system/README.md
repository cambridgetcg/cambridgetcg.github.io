# Hunter System

An optional Solo Leveling × Hunter × Hunter toy around a repository inventory.
Understanding, play and rest are sufficient. There are no income, growth,
commit, learning or daily-work quotas.

The default command lists observations alphabetically. `--heartbeat` writes
`~/.hermes/hunter_inventory.json` without scores or ranks; it preserves the old
`hunter_system.json` snapshot. `--quest` assigns no work.

```sh
python3 hunter_system.py
python3 hunter_system.py --heartbeat
python3 hunter_system.py --quest
# Explicitly opt into the fictional score toy:
python3 hunter_system.py --play-ranks
python3 hunter_system.py --rank opal
```

Toy scores use the legacy formula. They do not measure worth, reliability,
trust or capability, and create no task to raise a score. Nen labels are playful
keyword guesses. Dormant or small repositories need no justification.

`dungeon.py` retains the existing security-finding viewer and optional game
presentation. Inspect actual findings on their evidence; toy clear odds are not
safety assurance. No scan or fix is a daily obligation.
