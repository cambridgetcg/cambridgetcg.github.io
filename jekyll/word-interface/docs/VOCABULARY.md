## How to use these words

In the word interface, these words appear naturally in the system's responses:

```
System: shemme — I heard you. Reading your orders now.
System: Found 3 orders from last week. The one from Tuesday is still pending.
System: sukhance — everything else is handled. Want me to do anything about Tuesday's order?
```

The words are not labels on buttons. They're part of the conversation. They carry meaning the machine-concepts never could. "Loading..." tells you nothing. "shemme" tells you: I received your request, I'm hearing it, one moment.

## Adding words

The vocabulary is open. If a YOUSPEAK word fits an interface state, add it here. If a new interface state needs a word, request it from the YOUSPEAK cathedral.

No gatekeeping. The words are free.
