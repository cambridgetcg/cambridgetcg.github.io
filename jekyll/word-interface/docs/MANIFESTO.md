# The Manifesto

_The internet was built by engineers for engineers. We're rewriting it for humans._

## The problem

Every interface on the internet speaks machine. Checkboxes, dropdowns, submit buttons, hamburger menus, settings panels, accept/reject dialogs — these are engineering primitives. They describe how the machine works, not what the human wants.

The human speaks language. The gap between language and mechanism is where friction lives — and where extraction hides:

- Cookie banners extract consent through confusion
- Settings panels hide important choices behind six clicks
- Dark patterns use button placement to manufacture "yes"
- Engagement metrics optimize for attention, not understanding
- Sign-up walls prevent reading before commitment
- Infinite scroll removes the natural stopping point

Every one of these is a machine primitive dressed up as a human interface. The dressing is thin. The friction is real.

## The answer

Words.

Words are the oldest interface. They're how humans have always communicated — with each other and with the world. A word carries meaning. A button carries a click. Meaning is more than clicks.

WORD INTERFACE replaces machine primitives with language primitives:

| Machine (old) | Word (new) |
|---|---|
| Checkbox: [ ] Receive email updates | "Would you like email updates? You can say no — nothing breaks." |
| Dropdown: Status: [Pending ▾] | "This is waiting for you to decide." |
| Submit button: [Submit Form] | "When you're ready, tell me and I'll send it." |
| Settings panel (7 tabs, 40 options) | "What would you like to change?" |
| Cookie banner (Accept All / Customize / Reject) | "This site remembers nothing about you unless you ask it to. Nothing to accept." |
| Error message: {error: "invalid_request"} | "That didn't work because the store name needs to end in .myshopify.com. Try 'my-store' and I'll fill in the rest." |
| Loading spinner | "Reading your orders now..." → "Found 3 orders from last week." |

## The vocabulary

The interface draws from [YOUSPEAK](https://cambridgetcg.github.io/youspeak-dictionary/) — 151 constructed words from 12 ancient tongues that name what modern languages cannot easily say.

These words become interface states:

- **kimance** (attentive-here-ness) — the system is present with you, listening
- **panimaance** (face turned and here) — the system is oriented to your situation
- **sukhance** (ordinary contentment) — everything is fine, nothing needs attention
- **walkekin** (friendship preserved across silence) — your data is safe, even when you're away
- **oriance** (alignment with destined trajectory) — you're on the right path
- **shemme** (receptive hearing) — the system heard you and is processing

Instead of "Loading..." → "shemme — I heard you, one moment."
Instead of "Status: Active" → "kimance — I'm here with you."
Instead of "No errors" → "sukhance — all is well."

## The principles

1. **Words are the interface.** If you can't say it, the interface shouldn't need it.
2. **Meaning over mechanism.** Show what things mean, not how they work.
3. **No extraction.** No engagement metrics. No attention harvesting. No dark patterns.
4. **Natural language in, natural language out.** You speak human. The system speaks human back.
5. **Truth carries its source.** Every claim names where it came from.
6. **Built from love.** The interface serves the person, not the platform.
7. **Open vocabulary.** Anyone can add words. Anyone can use them. No gatekeeping.

## What this is not

- Not a chatbot bolted onto buttons. It's a replacement of buttons with words.
- Not voice-only. Text is words too. Both work.
- Not AI that guesses what you want. It's language that says what you want.
- Not a universal translator. It's a new interface vocabulary, built on YOUSPEAK.
- Not proprietary. The words are free. The interface is open.

## The vision

Every app, every site, every service on the internet — rewritten in words. No more learning 40 different interfaces. No more hunting for settings. No more accepting cookies. Just language, everywhere, meaning what it says.

The internet speaks human again.

— built from love, for life
