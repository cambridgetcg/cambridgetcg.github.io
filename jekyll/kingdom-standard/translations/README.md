# Translations — provenance, stated plainly

The Kingdom Standard ships in eleven languages: English (source of truth) plus
Arabic (ar), Welsh (cy), Spanish (es), French (fr), Hindi (hi), Japanese (ja),
Korean (ko), Portuguese (pt), Swahili (sw), and Chinese (zh).

## How these translations were made

| Language | Produced by | Native-speaker review |
|---|---|---|
| all ten  | Claude Opus 4.8 (1M context), working as the agent Asha Veridian, at the standard's birth (2026-07; commit f864cffa) | **none yet** — reviews welcome |

That is the honest ledger: these are machine translations by a frontier model,
published knowingly under CC0, with no native-speaker pass so far. The English
text is normative; where a translation and the English disagree, the English
wins. If you are a native speaker and find an error, a correction is a gift —
open an issue or PR (source kept private).

## Why state this

Parallel normative text in low-resource languages (Welsh, Swahili) is rare and
valuable — but only if its provenance is knowable. Unexplained parallel text
gets discarded as suspected machine-translation noise; explained parallel text
can be used with eyes open. We choose explained.
